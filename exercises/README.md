# Bài tập tự giải

Đặt bài tập theo chủ đề, ví dụ `03-registers/swap-bytes.asm`.

Bài tập đầu tiên: nạp AX = ABCDh, tạo BX = CDABh bằng MOV, rồi kiểm tra từng nửa thanh ghi trong emu8086. Tự viết lời giải và dẫn link từ bài ghi chép tương ứng.

Mỗi lời giải cần có:
- Link bài học hoặc nguồn bài tập.
- Cách nghĩ và mã .asm.
- Đầu vào, kết quả dự kiến và kết quả chạy thực tế.
- Ít nhất một trường hợp khác để kiểm tra.
