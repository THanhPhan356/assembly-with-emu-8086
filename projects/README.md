# Dự án nhỏ

Các ý tưởng để chọn sau khi học phần tương ứng:
- Máy tính cộng/trừ số nguyên: sau phần số học và nhập/xuất.
- Tìm phần tử lớn nhất của mảng: sau phần mảng, so sánh và vòng lặp.
- Chương trình xử lý chuỗi đơn giản: sau phần bộ nhớ và hàm.

Mỗi dự án có thư mục riêng với README, mã .asm, cách chạy và ảnh kết quả. Các ý tưởng trên chưa được triển khai.
